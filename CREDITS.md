# Credits

Everything visual and audible on this site is made in code for this project: the 3D tunnel (three.js geometry and
GLSL shaders), the light gates and sparks, the no-WebGL poster (SVG), the favicon (SVG), the Open Graph image
(`next/og`) and the demo music set (synthesised live with the Web Audio API). There are **no third-party images,
3D models, textures or audio files** in this repository.
